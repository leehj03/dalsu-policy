계정 및 데이터 삭제 안내

앱에서 직접 삭제하거나, 앱을 사용할 수 없다면 운영자에게 요청할 수 있습니다.

달수 계정 삭제 방법

달수(Android 앱)에서는 다음과 같이 계정과 클라우드 백업을 삭제할 수 있습니다.

  1. 달수 앱 실행 → 설정 탭
  2. Google 계정 연결 열기
  3. 달수 계정 영구 삭제 선택
  4. 확인 문구 입력 및 Google 재인증 후 삭제 완료 확인

달수 계정 삭제는 Google 계정 자체를 삭제하지 않습니다.

앱을 사용할 수 없는 경우

앱 삭제, 기기 분실 등으로 앱에서 삭제할 수 없다면 아래 연락처로 달수 계정 삭제 요청을 보내세요.

계정 삭제 요청 이메일 보내기

서비스 운영자: 이현진
문의 이메일: dalsu.app.support@gmail.com

가능하면 달수에 로그인한 Google 계정 이메일로 보내고, 제목에 달수 계정 삭제 요청이라고 적어 주세요. 비밀번호, 인증번호, 주민등록번호는 요청하지 않습니다.

계정 소유 확인을 거쳐 삭제 절차를 안내하고, 요청이 처리되면 결과를 회신합니다. 앱 외부에서 계정 삭제를 원격으로 진행하는 서버 기능은 별도 구축되지 않았으므로 운영자의 수동 처리 절차가 필요합니다.

삭제되는 정보와 남는 정보

  • 삭제: 달수 Firebase Authentication 계정 및 연결된 Cloud Firestore 클라우드 백업
  • 유지: 본인의 Google 계정 자체, 휴대전화에 저장된 달수 SQLite 공부·조개 기록
  • 기기 데이터 별도 삭제: 휴대전화 설정에서 달수 앱 데이터 삭제 또는 앱 제거

단순 로그아웃이나 클라우드 백업만 삭제는 달수 계정 삭제와 다릅니다.
